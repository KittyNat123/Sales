# 🛒 온라인 채널 제품 판매량 예측 프로젝트

[DACON - 온라인 채널 제품 판매량 예측 AI 경진대회](https://dacon.io/competitions/official/236129/data)

## 📌 프로젝트 개요
과거의 제품 판매량, 브랜드 검색량(Keyword) 등의 시계열 데이터를 활용하여 향후 21일간의 제품별 일별 판매 수량을 예측하는 프로젝트입니다. 초기 단일 글로벌 LSTM 모델에서 발전하여, 다양한 트리 기반 및 딥러닝 모델을 실험하고 앙상블하는 구조로 완성되었습니다.

* **예측 대상:** 약 15,890개 제품의 미래 21일 판매량
* **학습 데이터:** 2022-01-01 ~ 2023-04-04 (459일치)
* **예측 기간:** 2023-04-05 ~ 2023-04-25 (21일)

## 🛠 데이터 분할 전략
* **Train:** 2022-01-01 ~ 2023-03-14 (438일) - 모델 학습
* **Validation:** 2023-03-15 ~ 2023-04-04 (21일) - 하이퍼파라미터 튜닝 및 조기 종료
* **Test (제출용):** 2023-04-05 ~ 2023-04-25 (21일)

## 📊 주요 수행 과정 (7 STEPS)

1. **환경 설정 및 데이터 로드**
   * 데이터 Downcasting 적용 (메모리 46% 절감)
2. **탐색적 데이터 분석 (EDA) & 시각화**
   * 제품 카테고리 불균형 확인 (상위 카테고리 임베딩 전략 도출)
   * 판매량 Long Tail 분포 확인 및 Log1p 변환 근거 마련
3. **데이터 전처리**
   * 8개 전처리 과정 수행 및 회복기 피처 설계
4. **특성 공학 (Feature Engineering)**
   * 시계열 데이터 정규화 및 Train/Val 세트 분리
5. **모델링 및 실험**
   * 총 7개 예측 모델 구성 및 비교 실험
   * 사용 모델: 베이스라인 3종, LightGBM, Attention 기반 모델, N-HiTS, TFT
6. **하이퍼파라미터 튜닝**
   * Optuna를 활용한 튜닝 진행 (LightGBM 100회, 딥러닝 30회 탐색)
7. **최종 앙상블 및 제출**
   * 다중 모델 예측 결과 앙상블 적용
   * 역변환 등 후처리 후 최종 예측 `submission.csv` 파일 생성
